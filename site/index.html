Execution-grounded research-integrity verifier

Run the paper.
Check its numbers.

Plumb re-runs a paper's own code and data on your compute, re-derives its quantitative claims from what the run actually produced, and returns a per-claim, reproducible verdict — REPRODUCED, DIVERGED, or UNVERIFIED. Execution decides. Never a model's opinion.

The 60-second demo

Once cloned, the replay needs no network, no environment build, and no API key. The paper ships with a record of its own run; the verdicts are re-derived from those committed bytes alone. 

$ git clone https://github.com/haqaliz/plumb && cd plumb
$ uv run plumb verify --from-record fixtures/gate/rcai

The verdict

Deliberately conservative. UNVERIFIED is never dressed up as REPRODUCED.

REPRODUCED

The paper's value was re-derived from its own run, within the precision the paper wrote.

WITHIN-TOLERANCE

Matches inside a stated numeric tolerance, not exactly.

DIVERGED

The artifact's own run contradicts the paper's own claim — never a harness failure.

UNVERIFIED

We could not decide: the repo won't run, the claim won't bind, the result is stale. The honest default.

A model may extract a claim or propose a binding. Execution assigns the verdict. Every DIVERGED carries review_required.

How it works

  1. IntakePaper claims extracted and selected by rule; the code pinned to a tree hash with a frozen environment.
  2. RunThe repo's own entry point executed on your compute — script, console entry, or notebook. Outputs content-addressed, stale files never read.
  3. Re-deriveEach claim bound to the value the run actually produced — JSON pointer, stdin, CSV cell, notebook cell or HTML table cell.
  4. DecideCompared in pinned Decimal at the paper's written precision. Execution yields the verdict.
  5. ProveA hash-listed, signed, replayable bundle a third party can re-run byte-identically. A finding nobody can replay is an opinion.

Why you can check it

Execution decides

No verdict comes from a model's opinion. A harness failure resolves to UNVERIFIED, never DIVERGED.

Signed, replayable bundles

Paper hash, tree hash, environment, traces and verdicts, signed with ssh-keygen and replayable offline.

Runs on your compute

The paper, code and data never leave your machine. Only hashes and verdicts you choose to publish ever do.

What a DIVERGED does and does not assert →

Honest limits. Live mode is expert mode today: --bindings is hand-written and there is no binding proposer yet. Most papers ship no runnable code, and figure-only results are not reachable. When Plumb cannot decide, it says so.
