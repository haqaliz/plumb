  the verdict is `STALE_ARTIFACT` and **zero reads** occurred; (b) guard scenarios: add a

## Edge cases & verdicts

| Case | Outcome |
|---|---|
| Unknown kind / bad fields / non-RFC pointer | `BindingInvalid` (file) or per-entry `BINDING_INVALID` |
| Wrong artifact kind for the locator | per-entry `BINDING_INVALID` (D1 disjoint) |
| Cell artifact absent from locatable targets | `NO_BINDING` |
| Pointer resolves to nothing | `NO_BINDING` |
| List/object node leaf (`/…/text`) | `UNPARSEABLE_VALUE` (D2, no auto-pick) |
| Non-numeric string leaf | `UNPARSEABLE_VALUE` |
| Stale notebook file | `STALE_ARTIFACT`, bytes never read (D3) |
| Tampered store bytes | `ValueError` propagates (unchanged, locate.py:16-19) |
| Run-level failure | run cause governs first (unchanged) |
