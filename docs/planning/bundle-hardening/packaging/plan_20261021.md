# Plan — bundle-hardening (#20)

## T1 — pack/unpack (`src/plumb/bundle/pack.py`)

RED tests (`tests/bundle/test_pack.py`):
- `pack(dir, out)` twice → identical bytes; extension `.tar` and `.tar.gz`.
- entries sorted, mtime 0, uid/gid 0, no uname/gname.
- `unpack` round-trips the committed AgroDesign bundle and it verifies.
- malicious archive (`../escape`, `/abs`, symlink, device) → refused, nothing written outside.

GREEN: `pack`, `unpack`, `is_archive`, refused-cause exception.

## T2 — `plumb bundle` CLI

RED tests (`tests/cli/test_bundle_cli.py`):
- `verify bundles/agrodesign --allowed-signers bundles/allowed_signers` → 0, summary on stdout.
- verify with a wrong principal → 1, `SIGNATURE_INVALID` on stderr, no traceback.
- verify an archive of the bundle → 0.
- `inspect` prints format/signer/run id and says the signature is not checked; `--json` parses.
- `pack` writes a file; packing a directory that is not a bundle → 1 named cause.
- missing `--allowed-signers` → 2.

GREEN: `src/plumb/cli/bundle.py` + subparser in `src/plumb/cli/__init__.py`.

## T3 — `created` timestamp

RED: `build_bundle(..., created=...)` → manifest carries it and verifies; without it the field is
absent and the old committed bundle still verifies; a non-string `created` is refused.

GREEN: `build_bundle(created=None)` → optional `"created"` in the manifest; `read_manifest`
accepts exactly one optional extra field.

## T4 — rotation + docs

Test: an `allowed_signers` with a retired key line plus the current key verifies; only the retired
key → `SIGNATURE_INVALID`. `bundles/README.md`: rotation procedure, the timestamp limit, and the
sigstore deferral with its reason.
