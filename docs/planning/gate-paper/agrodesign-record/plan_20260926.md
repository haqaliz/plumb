# Implementation plan — `gate-paper` / `agrodesign-record` (2026-09-26)

Sources: [`../prd.md`](../prd.md) (approved 2026-09-26), `../../_card/understanding.md`. One aspect: the
engine gaps the real paper exposed, then the gate record. Execution in the main thread (no
agent-dispatch tool in this session), strict TDD, a commit per phase gated on pytest's own
exit code.

## Engine gaps found at plan time (fixed first, test-first — PRD "Technical Considerations")

1. **Float repr is not a rounding.** pandas' `to_csv` and `json.dumps` write a binary64 as its
   shortest round-trip repr: the exact value 2.5 is written `2.5`. C4 reads written digits as
   precision, so the paper's `2.500` against the run's `2.5` is `ARTIFACT_PRECISION_COARSER` — a
   harness-side false `UNVERIFIED` (confirmed on the real outputs: Residual MS in Tables 1, 3, 7).
   Fix: an optional binding flag `"float_repr": true` declaring the artifact's numbers are
   shortest round-trip reprs; the located half-unit is then 0 (the value is the program's exact
   double). Never inferred — the binding says so, and the binding file is committed and audited.
2. **No trace loader.** Offline replay needs a `RunTrace` back from `trace.json`; C6 will too.
   Add `parse_trace(bytes) -> RunTrace`, the inverse of `serialize_trace`, round-trip pinned.

## Phases

### Phase G1: `float_repr` bindings (RED → GREEN)

- `tests/verify/test_bindings.py`: `float_repr` loads as a bool, defaults to `False`, a non-bool
  raises `BindingInvalid`; `tests/verify/test_locate.py`: a `float_repr` binding locates with
  `half_unit == 0`, text unchanged; `tests/verify/test_verify_seam.py`: CSV `2.5` against a
  paper `2.500` is `ARTIFACT_PRECISION_COARSER` without the flag and `REPRODUCED` with it.
- `src/plumb/verify/bindings.py` (`Binding.float_repr`, schema), `locate.py` (half-unit), docs.
- Commit: `Bind shortest-repr floats as exact: float_repr on a binding`

### Phase G2: `parse_trace` (RED → GREEN)

- `tests/run/test_trace.py`: `parse_trace(serialize_trace(t)) == t` for a real run, a failed
  run and a run with stale outputs; malformed input raises `ValueError`.
- `src/plumb/run/trace.py`, exported from `plumb.run`.
- Commit: `Parse a serialized RunTrace back, the inverse of serialize_trace`

### Phase G3: the paper fixture and curated claims (RED → GREEN)

- `fixtures/gate/agrodesign/paper.pdf` (arXiv:2603.09041v1, CC BY 4.0) + `README.md`
  (provenance: URLs, licenses, SHA-256, pinned rev).
- `fixtures/gate/agrodesign/claims.json` — the rule-defined set (PRD P2): every numeric cell of
  Tables 1–8 and every F / p / Shapiro-Wilk value in §4's prose; each entry
  `{text, metric, start, end}` against `normalize_text(pdf_to_markdown(pdf))`.
  `unrepresentable.json` — members of the rule that cannot be a `Claim` (the PDF renders `<` as
  `¡`: "p ¡ 0.001" twice), with the reason.
- `tests/gate/test_agrodesign_fixture.py`: PDF hash; every claim grounded verbatim at its span
  and parseable; ids unique; the rule's count (claims + unrepresentable) pinned; C1's automatic
  recovery of the curated ids pinned (today 0) with its rejection causes.
- Commit: `Add the AgroDesign gate fixture: paper, provenance, grounded claims`

### Phase G4: bindings, driver, the dev-time run (RED → GREEN)

- `fixtures/gate/agrodesign/bindings.json` — `csv_cell` (+ `float_repr`) into
  `results/<design>/tables/*.csv`; `stdout_regex` anchored at `===== <design>` for the report

  checked), `parse_trace`, `verify_claims`, byte-identity with `verdicts.json`; every binding's
  claim id is in `claims.json`; no absolute path in any committed file.
- Run the tool once (network authorized). Commit: `Run AgroDesign through the spine: the first
  real-paper verdicts`

### Phase G5: the number, docs (S1, S2)

## Determinism & offline

Tests never touch the network (autouse socket block). The only networked code is
`tools/gate_run.py`. Verdicts depend only on committed bytes; the replay test is the check.
