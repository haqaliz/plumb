# Gate-paper survey (2026-09-25)

Goal: one real, public, runnable paper to push through intake → run → verify for the Phase 0
gate (`docs/ROADMAP.md`). The owner authorized the dev-time fetch and delegated the pick.

## Selection criteria (what the built spine can verify today)

1. Paper text openly licensed (CC BY) so it can be a fixture.
2. Public code, pure Python, runs on a laptop CPU in minutes, **no network at run time**.
3. Data bundled or generated by the code; nothing gated.
4. Headline numbers **printed or written as JSON/CSV by a script** (C3 captures stdout/JSON/CSV;
   notebook capture is not built).
5. Deterministic, or seeded, so a value can be `REPRODUCED` within the paper's written
   precision; C4 compares `Point`/`Bound` values only.

## Source

The full ReScience C catalogue (`ReScience/rescience.github.io`, `_bibliography/published.bib`,
sources branch): every article is CC BY with a public code repository. Plus the 26
`ReScience-Archives` repositories, whose article sources are Markdown, scanned for numeric
tables.

## Finding (R1 evidence)

Across the whole catalogue of a journal that exists *to* publish reproducible computations,
no entry meets all five criteria. The failures cluster into three mechanisms, each one a
concrete R1 coverage gap:

1. **Results live in figures, not numbers** — the most common case.
2. **Results live in notebooks** — the table is computed in `analysis.ipynb` from a pickle; the
   repo's scripts write only intermediate state. Needs C3 notebook capture (named follow-on).
3. **Stochastic, unseeded aggregates** — e.g. `92.34 (1.26)` over 500 random landscapes. Such a
   value cannot be reproduced to its written precision; it needs a tolerance derived from the
   reported spread, which the first C4 slice deliberately does not infer.

This is an honest negative for the gate: the verdict spine works, but the first real paper
needs either a wider search outside ReScience, or one of the extensions above.
