## Edge cases & error handling

- **Empty column header / row label:** use the non-empty part; both empty ⇒ no name.
- **Multi-row header** (a header that is a data row, `PMC12780771.md:131`): out of scope — the
  cell is named by its row label only; documented.
- **Sample-size labels** (`n = 1578`, `n`, `N`): must stay metric-less (`_N_TOKENS`).
- **Ragged rows:** `dict.get` ⇒ `""` (no crash), matches `labelling`.
- **No near caption:** `table_index=None` ⇒ `{row_label} {column_header}`.
- **Id stability:** the fallback guarantees an existing in-cell metric is never overridden.
