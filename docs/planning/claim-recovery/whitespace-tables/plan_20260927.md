## 0. Findings that shape the plan (measured before planning)

- **Pipe-table cells carry no naming today.** A cell's context is its own text
  (`candidates.py:571-576`), so a bare numeric cell is refused `no_named_metric`
  (`test_selection.py::test_a_bare_number_without_a_quantity_phrase_is_not_a_claim`).
  There is no pipe-table metric to "match"; the greenlight question resolves to: **the
  new naming applies to caption-led whitespace tables only, and pipe tables are
  unchanged.** Consequence: the Markdown path of every fixture — the seam test's
  denominator — cannot move. Naming pipe cells is a named follow-on.
- **The fixture PDFs' tables do not fit the strict shape.** On the PDF path their captions
  wrap over several lines and are followed by caption continuations, pipe fragments or
  mixed header text, not by rows. A rule that requires rows (or one header line) directly
  after a single caption line should fire on AgroDesign and, at most, rarely elsewhere.
  Phase 3 measures it; any fixture claim change is listed and reviewed.
- **The converter stays frozen** (bundle re-admits at recorded offsets): everything below is
  in `extract/`.

## 1. Design

**Recognition** (`extract/tables.py`, new `parse_captioned_tables(text)`), per line:
- *Caption*: a whole line matching `^Table (\d+)[:.]`. The table number is group 1.
- *Header* (optional): the next line, if it is not a row, not an ATX heading, has no
  purely-numeric token, and has ≥ 2 tokens.
- *Row*: whitespace-split tokens; the **cells** are the longest suffix of cell tokens —
  a number (`-?\d+(\.\d+)?`), a dash (`–`, `-`, `—`), or a glued `number<number` /
  `number>number`, which is two cells (`145.333` and `<0.001`); the **label** is the rest,
  and must be non-empty and contain a letter. ≥ 1 cell.
- A table is a caption, the optional header, then **≥ 2 consecutive rows**; it ends at the
  first line that is not a row. Anything else yields no table (the caption's numbers stay
  prose, as today).
- *Column names*: if the header has exactly `cells + 1` tokens, token `k+1` names cell
  `k` (the first names the label column); otherwise `column {k}` (1-based). Decided per
  row, so a ragged row falls back to ordinals rather than misnaming.
- A dash cell counts for column position and yields no cell record.

**Record**: `CaptionedCell(cell: TableCell, header: str)`, where `header` is
`Table {n} {row label} {column name}`, e.g. `Table 1 Treatment MS`,
`Table 3 Nitrogen×Spacing column 3`. The table's `Table.span` runs from the header (or the
first row) to the end of the last row, so `_line_kinds` treats those lines as table lines.

**Candidate**: gains `cell_header: str | None = None` (validated `str | None`). Set only for
captioned-table cells; context is the cell text, exactly as for pipe cells; hint `table`.
The field is structural — the words the paper wrote in the row and header — not a
judgement, and the docstring says so.

**Selection**: after every lexical check (unchanged order), a candidate with a
`cell_header` takes it as its metric instead of `metric_of`, except that a header whose row
label or column name is an N-token (`_N_TOKENS`) is `no_named_metric` — the sample-size
fall-through stays closed for this path too.

**Identity**: `Claim.id` hashes `(text, metric, units)`; two cells now differ in the
metric wherever they differ in table, row or column, so distinct cells no longer collide.

## 4. Testing strategy
Synthetic text for every rule; AgroDesign as the integration check; the regression net is
the full suite (blind score, seam, pdf fixtures, determinism, bundle, replay).

## 5. Environment & determinism
No new dependency or network. Line/regex rules only; determinism is covered by
`test_determinism.py` (candidates are sorted by location; the new field is a plain string).

## 6. Edge cases
- A caption followed by a wrapped caption line that happens to end in numbers: must have
  ≥ 2 consecutive row-shaped lines to be a table; a single one stays prose.
- A row label ending in a number (`Model 2 0.87`): the `2` becomes a cell. Can't be told
  apart from the text; the header-count rule then falls back to ordinals rather than
  misnaming. Documented limit.
- Negative values (`G2 -2.3`): the sign belongs to the cell (tokenisation already keeps it).
- Table 8's header arrives as `## Genotype BLUP` (a heading): ordinal columns — honest.
- No verdict changes; nothing here can produce `DIVERGED`.
