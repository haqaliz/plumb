### Phase 1 — Unreadable comparator is a fragment (M3)
- **Test first** (`tests/extract/test_admit.py`): `admit` on the `0.001` of `p ¡ 0.001` and

- **Code:** `src/plumb/extract/admit.py` — add `¡¿` to `_OPERATOR_BEFORE`'s class, and a
  comment line citing LaTeX OT1 (`<`→`¡`, `>`→`¿`) and why this is refusal, not repair
  (the text can't change: the signed bundle re-admits at recorded offsets).
- **Validation:** `uv run pytest tests/extract/test_admit.py`
- **Commit:** `Refuse a number behind an OT1 comparator glyph as a fragment`

### Phase 2 — Significance level is a design input (M5)
- **Test first** (`tests/extract/test_selection.py`): `0.05` in `Tukey HSD groupings atα=
  0.05` and in `at a significance level of 0.05` and `alpha = 0.05` → `hyperparameter`;
  `0.87` in `The AUC was 0.87` still selected.
- **Code:** `src/plumb/extract/selection.py` — extend `_HYPERPARAM_CUES` with
  `significance level|alpha` inside the `\b…\b` group and a separate unbounded `α`
  alternative (`atα` has no word boundary before `α`).
- **Validation:** `uv run pytest tests/extract/test_selection.py tests/extract/test_blind_score.py`
- **Commit:** `Treat a significance level as a design input, not a result`

### Phase 3 — `layout_numeral` (M4)
- **Test first** (`tests/extract/test_selection.py`):
  - vocabulary: `CAUSE_LAYOUT_NUMERAL == "layout_numeral"` is in `SELECTION_CAUSES` and
    `__all__`; the disjointness and module-constant tests still pass unchanged.
  - refused: `4.1` in `## 4.1 Completely Randomized Design`; `4` in `# 4 Experimental
    Validation`; `8` on a line alone between two prose lines; `1` in `1. Correct
    identification of the model` (line-leading).
  - not refused: `0.87` in a body line under `## Results`; `3` in `Treatment 3 363.333`
    (a row's first number isn't line-leading); `2` in `1.2 Results` body text mid-line;
    `12` in a heading `## Results at 12 months` (only the numbering *prefix* of a heading).
- **Code:** `selection.py` — new constant + vocabulary entry; a check placed **directly
  after the section checks**, before `year`; update the check-order comment. The check reads
  the candidate's line from `normalized_text` (line start = `rfind("\n")`):
  - heading: the line matches `^#{1,6}\s+` and the candidate is the first token after the
    hashes (the numbering prefix, `\d+(\.\d+)*\.?`);
  - page number: the whole stripped line equals `candidate.text` and it is a bare integer;
  - list marker: the candidate is at line start, is a bare integer, and is followed by
    `.` or `)` and a space.
- **Validation:** `uv run pytest tests/extract/`
- **Commit:** `Refuse layout numerals: heading numbers, page-number lines, list markers`

## 4. Testing strategy

  (offline; the PDF is committed).
- Regression net: `test_blind_score.py`, `test_pdf_seam.py`, `test_pdf_fixtures.py`,

## 5. Environment & determinism
No new dependency, env var or network. All rules are regex/line structure over the
normalized text; `test_determinism.py` covers cross-process byte identity.

## 6. Edge cases
- `¡` used as Spanish punctuation before a number (`¡3 goles!`) → refused `partial_value`:
  a false negative, the safe direction; documented in the comment.
- A heading whose title *is* a number (`## 2024`) → the prefix rule refuses it; fine.
- A PDF wrap leaving a genuine value alone on a line → refused `layout_numeral` (named false
  negative). Phase 5 surfaces any on the fixtures.
- Nothing here emits or alters a verdict; no `UNVERIFIED` path changes.
