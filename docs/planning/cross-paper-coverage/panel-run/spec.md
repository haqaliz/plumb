# Spec — panel-run (cross-paper-coverage, aspect 2)

Source: `docs/planning/cross-paper-coverage/prd.md` R4–R6, S1–S3 (approved 2026-10-02).
Depends on: the `bank-flag` aspect (commits a61de66..12e3c23 — `--bank`, dual-form read,
record writer).

## Problem slice

Run a small panel of real runnable papers through the spine and bank each case, so the
first honest multi-paper coverage/precision/recall figure exists (the R1 measurement).

## The fixed selection rule (written 2026-10-02, BEFORE any paper is chosen)

The panel is 3–5 papers (target 4; floor 2 — AgroDesign is case #1 and does not count
toward the floor). A candidate paper qualifies only if **all** of these hold:

1. **License** — paper text openly licensed (CC BY 4.0 or equivalent) so it can be
   committed as a fixture with attribution; code repo public (git URL) at a pinned rev.
2. **Language/runtime** — pure Python (or R) data analysis; runs in laptop-CPU minutes
   (≤ ~20 min).
3. **No run-time network** — data bundled in the repo or generated by the code (seeded);
   nothing fetched during the run.
4. **Machine-readable headline numbers** — the headline quantitative claims (results
   tables, reported statistics) are printed by a script or written as JSON/CSV, so the
   C4 locator types (`json_pointer`, `csv_cell`, `stdout_regex`) can reach them.
   Notebook-only or figure-only results disqualify (the ReScience screening already
   showed this is the dominant failure mode, `docs/planning/gate-paper/survey.md:40-54`).
5. **Determinism** — deterministic or explicitly seeded, so re-derivation can match the
   paper's written precision.
6. **Claims rule fixed before binding** — per paper, the claims are defined by a written
   rule (which tables/statements count) BEFORE any run or binding; each claim's text must
   occur verbatim at a found span (grounded, never typed); unparseable rule members
   become non-claims with reasons (anti-inflation, `docs/planning/gate-paper/prd.md:37-45`).
7. **Not AgroDesign** (case #1).

Selection: the owner; screening may be delegated. Every candidate — qualified or not —
is recorded in a screening note with the failing criterion; the note is the evidence.
If fewer than 2 qualify after a documented wider search (arXiv), the note IS the R1
finding, reported with zero padding.

## Per-paper template (each paper lands as its own committed unit)

- `fixtures/gate/<slug>/` — `paper.pdf`, provenance `README.md` (SHA-256 pinned,
  license, URLs, the claim rule, the number, deviations, limits — the
  `fixtures/gate/agrodesign/README.md` shape), `source.json`, `claims.json` (curated
  form), `bindings.json`, `unrepresentable.json` (rule members that cannot parse, with
  reasons), `trace.json`, `objects/` (locatable only), `verdicts.json`,
  `environment.txt` (resolved env freeze), and — only where a `DIVERGED` appears —
  `drift.json` (M4a older-environment cross-check) and `labels.json` (owner review,
  transported never created).
- `tools/<slug>_spec.py` — the rule encoded as data tables; spans FOUND via exactly-once
  context search (`unique_offset`), never typed; claims + bindings + unrepresentable
  derived together; the `DRIVER` argv transcribing the paper's workflow with deviations
  disclosed (the `tools/agrodesign_spec.py` shape).
- Dev-time run — `tools/gate_run.py` shape: `resolve_git` at the pinned rev, real env
  build + `uv pip freeze`, run in a working copy, locatable-only objects, write the
  record. Real env builds are dev-time only, never in tests/CI
  (`tools/demo_env_build.py:1-16` precedent).
- `tests/gate/test_<slug>_fixture.py`, `test_<slug>_replay.py` — grounding, PDF-hash
  pin, rule count, byte-identical replay from committed objects, no-local-path scan.
- C1 recovery measured per paper (place+value) and reported as conformance; a recovery
  floor test (the `test_agrodesign_recovery.py` shape) only where the measured recovery
  clears it — otherwise the gap is documented, never tuned silently.
- Bank: `plumb corpus bank fixtures/gate/<slug>/` (or `--from-record --bank`).

## Out of scope

- Findings publication / author contact (owner decision, `gate-paper/prd.md:65-68`).
- The binding proposer, notebook locators, C7, C8, public corpus export.
- Retuning C1 per paper beyond honest measurement: a paper whose claims C1 cannot
  recover is a finding, not a silent retune (`CAPABILITY_ROADMAP.md:85-87`).

## Acceptance criteria (written first)

1. The selection rule above is committed BEFORE any paper is chosen; the screening note
   records every candidate with the failing criterion (or the satisfied rule).
2. At least one new paper (besides AgroDesign) runs end-to-end at dev time and banks:
   its case re-derives from its stored trace matching its `verdicts.json`; its fixture
   tests (grounding, PDF hash, no local paths) pass; `corpus report` pools ≥ 2 cases.
3. Every panel paper: recovery measured and reported; a `DIVERGED` appears only with the
   M4a drift cross-check and an owner review recorded (labels transported).
4. No network in tests; env builds dev-time only.
5. The honest pooled number is computed over the banked panel with per-case and pooled
   denominators and authority markers — the R1 measurement exists (reported in the
   `r1-report` aspect).

## Sequencing

1. Commit this spec + the selection rule (this commit — the rule precedes selection).
2. Screening note (search + candidates vs rule).
3. Paper 1 end-to-end (fixture, spec, run, record, bank, tests) — the floor milestone.
4. Papers 2–3 (independent; each its own commit).
5. Recovery measurement per paper + report pooling verified over the panel.

## Open questions

- Panel papers' environments are resolved, not locked (best-effort; the AgroDesign
  precedent) — drift is recorded, not assumed away (M4a applies to `DIVERGED`s).
- R papers (vs Python): the run spine is Python-first (`uv`); an R paper requires R
  tooling not yet in the engine — the rule's "pure Python (or R)" is aspirational for R
  today; the panel defaults to Python papers until R capture exists. State this in the
  screening note.
