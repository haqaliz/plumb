# Implementation plan — `notebook-capture` / `capture` (2026-10-08)

Source: `docs/planning/notebook-capture/prd.md` (M3–M6) + `capture/spec.md`.
Baseline: `uv run pytest -q` green at 1921 after the `entrypoint` aspect. Strict TDD; one
agent per phase.

## Setup checklist

- No new package, no new deps, no new causes. Touch only `src/plumb/run/capture.py` and
  `tests/run/test_capture.py` (docstring updates included).
- Reuse the existing test patterns in `tests/run/test_capture.py`: `committed_checkout`,
  back-dating helpers, store assertions, and the strict-boundary test.

## Phases

### Phase C1: notebook walk + whole-file artifact + freshness (RED → GREEN)

- **Goal:** a fresh `.ipynb` is captured as one `notebook` artifact (raw bytes, sha256,
  size, mtime); a stale one is a `StaleOutput` and its bytes are never read.
- **Files:**
  - `tests/run/test_capture.py` — failing tests: a fresh notebook in the working copy →
    one `Artifact(kind="notebook", relpath=..., sha256=hash(raw bytes), size, mtime_ns)` and
    `Capture.read` returns the raw bytes; a back-dated notebook → `StaleOutput` with the
    notebook relpath, no `notebook` artifact, and its sha absent from the store; the
    strict-boundary test extended to a notebook (`==` start fresh, `start-1ns` stale); a
    committed untouched notebook the run does not rewrite is stale.
  - `src/plumb/run/capture.py` — include `.ipynb` in the capture walk (keep `_OUTPUT_KINDS`
    for `.json`/`.csv`; branch on the suffix before the kind lookup), take the mtime/freshness
    decision before reading as today, and store the whole file as `kind="notebook"`. Update
    the module docstring and the `Artifact.kind` vocabulary comment.
- **Validation:** `uv run pytest tests/run/test_capture.py -q` green; `uv run pytest -q` green
  (1921 + new).
- **Commit:** `Capture notebooks whole-file, freshness-guarded like any output`

### Phase C2: per-cell artifacts, canonical projection, undecomposable fallback (RED → GREEN)

- **Goal:** each output-bearing cell becomes `kind="notebook_cell"` at `<relpath>#cell-<i>`
  with canonical projection bytes; undecomposable notebooks keep the whole-file artifact only.
- **Files:**
  - `tests/run/test_capture.py` — failing tests: a notebook with (a) a markdown cell, (b) a
    code cell with one `stream` output, (c) a code cell with empty `outputs` → one
    `notebook_cell` artifact at the right index whose `Capture.read` equals the canonical
    projection (sorted keys, compact separators, UTF-8, trailing newline) of the `outputs`
    array; two fresh notebooks both decomposed; undecomposable cases (bad JSON bytes,
    `cells` not a list, a `NaN` literal in an output with `allow_nan=False`) → whole-file
    artifact only, zero `notebook_cell` artifacts, no exception; identical notebooks produce
    identical cell shas.
  - `src/plumb/run/capture.py` — after storing the whole file, parse the bytes (`json`),
    iterate `cells` with index, and store canonical projections; wrap the parse/projection so
    any failure yields no cells (no cause, no drop of the whole file). Projection helper
    private to the module; reuse the house JSON parameters.
- **Validation:** `uv run pytest tests/run/test_capture.py -q` green; `uv run pytest -q` green.
- **Commit:** `Capture notebook cells as content-addressed outputs, canonical and undecomposable-safe`

## File-by-file build order

1. `tests/run/test_capture.py` (C1 RED) → `src/plumb/run/capture.py` (C1 GREEN)
2. `tests/run/test_capture.py` (C2 RED) → `src/plumb/run/capture.py` (C2 GREEN)

## Testing strategy

- Offline only; notebooks are synthetic JSON fixtures written by tests, never executed; no
  subprocess, no kernel.
- Freshness is the load-bearing guard: stale → never read (assert sha absent from the store);
  strict boundary preserved for `.ipynb`.
- Determinism: identical notebook bytes → identical whole-file and cell shas; artifact sort
  order asserted on a two-notebook case.

## Environment & determinism

- No new deps. `json` only. `run/trace.py` must remain byte-for-byte untouched — the new
  kinds flow through the existing generic `Artifact` records.

## Edge cases & error handling

- Bad JSON / non-list `cells` / non-dict cell / non-list outputs / `NaN` outputs → whole-file
  artifact only.
- `NO_ARTIFACT` unchanged: a fresh notebook counts as a fresh file even with zero outputs.
- Symlinks skipped as today; recursive walk unchanged otherwise.
