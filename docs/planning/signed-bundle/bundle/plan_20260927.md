# Implementation plan — `signed-bundle` / `bundle` (2026-09-27)

Sources: [`../prd.md`](../prd.md) (approved 2026-09-27, with the owner's OK to create a
dedicated `plumb-bundle` Ed25519 key outside the repo). One aspect. Main-thread execution (no
agent-dispatch tool in this session), strict TDD, one commit per phase, gated on pytest's own
exit code.

## Phases

### B1 — `parse_claims` (C1 inverse)
- `tests/extract/test_serialize_parse.py`: round trip is the identity for every value variant
  and for the gate claim set; ids recompute (a tampered id is refused); unknown kinds, extra or
  missing fields, and non-string decimals are refused with `ValueError`.
- `src/plumb/extract/serialize.py`: `parse_claims(data) -> (tuple[Claim, ...], PaperHash)`.

### B2 — SSHSIG signing seam
- `tests/bundle/test_sshsig.py`: sign → verify ok; deterministic; wrong key, wrong principal,
  wrong namespace, tampered data, empty signature → not ok; no shell, a fixed argv.
- `src/plumb/bundle/sshsig.py`: `NAMESPACE = "plumb-bundle-v1"`, `SshSigner(key_path, principal)`
  (`.sign(data) -> bytes`), `ssh_verify(data, signature, *, allowed_signers, principal) -> str | None`
  (None = good, else the reason). Tests make a throwaway key with `ssh-keygen` in tmp.

### B3 — `build_bundle` + manifest
- `tests/bundle/test_build.py` over a synthetic C3 run + C4 verify: the member set (only bound
  objects; no stderr); the manifest shape; two-process byte identity including the signature;
  refusals before signing (`BundleRefused` with a cause): a verdicts file that does not
  re-derive, a binding for an unknown claim, a local path in a structured member.
- `src/plumb/bundle/manifest.py`, `build.py`, `causes.py`.

### B4 — `verify_bundle`
- `tests/bundle/test_verify.py`: a built bundle verifies and returns the re-derived `VerdictSet`;
  one test per cause — `SIGNATURE_MISSING`, `SIGNATURE_INVALID` (wrong key / principal /
  tampered manifest), `MANIFEST_INVALID`, `MEMBER_MISSING`, `MEMBER_TAMPERED` (a flipped byte in
  each member kind), `MEMBER_UNLISTED`, `MEMBER_REFUSED` (stderr object; local path),
  `VERDICTS_MISMATCH` (verdicts re-signed after tampering); stage order (a bad signature stops
  before members are read); content problems never raise.
- `src/plumb/bundle/verify.py`, package `__init__` with the cause table.

### B5 — the AgroDesign bundle
- Key: `~/.ssh/plumb_bundle_ed25519` (created once, refused if it exists); public key committed
  as `bundles/allowed_signers` (principal `plumb-bundle`).
- `tools/bundle_build.py` (offline): builds `bundles/agrodesign/` from `fixtures/gate/agrodesign/`
  with the recorded source (`https://github.com/DeepStatistix/AgroDesign.git`, `v1.0.1` →
  `18b7c29a4f8de3dc9260b9fa42849e5a74097825`).
- `tests/bundle/test_agrodesign_bundle.py`: verifies against the committed `allowed_signers`;
  86 verdicts; identical to the fixture's `verdicts.json`.

### B6 — run replay + docs
- `tools/bundle_replay.py` (networked, by hand): clone at the rev, check the tree hash, `uv venv
  --python <recorded>`, `uv pip install --no-deps` the frozen pins and the checkout, run the
  trace argv through C3, compare the fresh `run_id` / bound object hashes with the bundle's;
  drift is reported per claim as `UNVERIFIED`, never `DIVERGED`. Result written to
  `bundles/README.md`.
- Docs: `ARCHITECTURE.md`, `CAPABILITY_ROADMAP.md`, `ROADMAP.md` (gate status per the PRD's
  three conditions), `CLAUDE.md`, `README.md`.
