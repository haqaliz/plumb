## Testing strategy

- Offline only: scripts are `python -c`/fixture files; no sockets; subprocess legal.
- Load-bearing tests: freshness guard (back-dated → STALE_ARTIFACT, never parsed),
  boundary (same-second fresh), run_id stability across processes.
- Determinism: trace byte-identity across processes (subprocess pattern).

## Environment & determinism

- No new deps. Run areas in tmp/.gitignore'd paths; relpaths only in records.
- run_id pinned input order: `argv + tree_hash + sorted artifact hashes`.

## Edge cases & error handling

- Named causes: `ENTRYPOINT_MISSING`, `ENTRYPOINT_AMBIGUOUS`, `WONT_RUN`, `TIMEOUT`,
  `ENV_BUILD_FAILED` (from C2), `STALE_ARTIFACT`, `NO_ARTIFACT` — each mapped to a future
  `UNVERIFIED` cause in the module docstring; never silent.
- `cp -p`-preserved old mtimes are stale by the guard (documented).
- Exit-0-with-no-output = success + `NO_ARTIFACT` (binding problem, not run failure).
