## Testing strategy

- The seam tests ARE the acceptance (pinned arithmetic, per-fixture floors).
- Unit tests pin the new geometric seams so a future refactor cannot silently lose column
  handling.
- Regression control: PMC13134363 (single-column) must not move.
- Determinism + no-network suites stay green throughout.

## Environment & determinism

- No new deps, no env vars, no network. Byte identity across processes stays pinned.
- Geometry from `tm`/`cm` is deterministic for fixed bytes; no floating-point tolerance
  randomness — use integer-ish thresholds with documented constants.

## Edge cases & error handling

- Gutter detection misfiring on single-column pages → control test (Cureus).
- Missing coordinates for some fonts → fall back to current single-column path, recorded.
- Header/footer false positives → prefer repetition + y-band; count drops in
  `ConversionStats`, never silently delete prose.
- pypdf tail-drop on Oxford PDF → residual documented if not fixable.
- Any fixture still below floor → M4 documented with new rate (never silent, never hard-fail).
