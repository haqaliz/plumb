## Phase 3 — Locator extension: HTML table-cell addressing (owner-approved amendment N1)

- **Goal:** a `notebook_cell` binding can address one `<td>` cell inside a pointed HTML
  leaf deterministically (pandas Styler renders — the dominant notebook-table path;
  finding recorded in the PRD N1).
- **Files:** `src/plumb/verify/bindings.py` (schema: `table` field, exactly
  `{"row": <int>, "column": <int>}`, non-negative, `BindingInvalid` on violation, per-entry
  `invalid` on mis-aim to a non-notebook_cell/pointer-less entry), `src/plumb/verify/locate.py`
  (post-resolution table extraction: split `<tr>` rows / `<td>` cells, strip tags, trim;
  out-of-range or no `<td>` → `NO_BINDING`; non-decimal text → `UNPARSEABLE_VALUE`;
  `float_repr` honored), `src/plumb/verify/serialize.py` + `src/plumb/cli/render.py`
  (canonical JSON + table rendering), tests: `tests/verify/test_bindings.py`,
  `tests/verify/test_locate.py`, `tests/verify/test_verdict_serialize.py`,
  `tests/cli/test_render.py`, `tests/verify/test_false_diverged_guard.py` (a table-mode
  stale-cell scenario), `tests/verify/test_cause_catalogue.py` (row, no vocabulary change).
- **RED first:** td splitting is pinned with synthetic Styler-shaped HTML (multi-row/multi-
  col grid, an entity in a cell, a `<td>` containing markup, a leaf without `<td>`); row/col
  schema refusals; out-of-range → `NO_BINDING`; the 2-decimal `12.90` leaf → `Located` with
  the written-precision band and verbatim text.
- **GREEN:** implement (the walk stays strict RFC 6901; the table mode applies to the leaf
  after pointer resolution; kinds stay disjoint; no new causes).
- **Validation:** `uv run pytest tests/verify tests/cli`; FULL suite green (1971 today).
- **Commit:** `feat(notebook-paper): notebook_cell locator gains HTML table-cell addressing (N1)`

## Phase 4 — Bindings, pre-registered readings (committed BEFORE the run)

- **RED first:** tests pin — every claim id in `claims.json` has exactly one binding; every

## Phase 5 — Dev-time campaign (supervised by the integrator; NOT pytest)

- **Goal:** the real run: pinned clone → env build (declared policy: README versions +

- **Files:** `tools/rcai_run.py` (AgroDesign `tools/gate_run.py` + Perrin driver shape),

- **Steps:** (1) write `tools/rcai_run.py`; (2) run it: resolve git at pinned rev (probe

  located values; (5) measure and record wall time in the README; (6) bank with
  `plumb verify --bank` / `corpus bank`; (7) record the drift note (fresh-resolve boundary).
- **Validation:** the record replays; two runs agree; suite still green.
- **Commit:** `feat(notebook-paper): committed record — <N> claims, <B> bound, <V> verdicts`

## Edge cases & honest outcomes

| Case | Outcome |
|---|---|
| PDF conversion cannot place §3/§4.2 spans | P2a HTML fallback, recorded |
| A claim has no fresh cell output on the run | `NO_BINDING`/`UNVERIFIED`, counted with denominators |
| The notebook file predates the run (never happens on the dev run; would on replay misuse) | `STALE_ARTIFACT`, bytes never read |
| A claim diverges (paper vs run mismatch) | `DIVERGED` + `review_required`, owner label |
| Env resolve differs from README versions | recorded freeze + drift note; verdicts decided only on the actual run |
| The 5 seated fixtures' floors move | stop — converter change is out of scope; investigate before proceeding |
