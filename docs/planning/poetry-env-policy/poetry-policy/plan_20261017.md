## Edge cases & error handling

- **Specifier pin** (`>=3.9` from `requires-python`): omit `--python` so uv picks; only a
  concrete pin is passed. Covered by `_venv_python_arg`.
- **No site-packages dir** (a pathological venv): treated as empty.
- **`declared` policy** installs into `checkout_dir/.venv`: the guard keys on that path, matching
  `run/runner.py:174`.
- **`--no-env-build` / stub runners**: never reach the guard (they bypass `uv_sync_runner`);
  pinned by keeping `build_environment` unchanged.
- **`best-effort` empty**: explicitly exempt (a dep-free project is legitimate).
