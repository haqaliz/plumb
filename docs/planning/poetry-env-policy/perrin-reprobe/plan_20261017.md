## Edge cases & error handling

- **Boundary still unbuildable at the paper era:** keep `--exclude-newer 2024-06-18` and record
  it; do not treat the drift as a failure of the poetry policy.
- **`uv pip install <checkout>` cannot resolve Perrin:** record it as a probe result (the policy
  is still correct; the repo is the edge case) and keep the README note.
- **Label-only churn:** if the only change is the `env_policy` string with no new information,
  prefer the README note (spec open question) — avoid moving committed bytes and pinned tests for
  no signal.
