## Phases

### Phase V0: foundation — causes and strict numbers (RED → GREEN) — **run first, shared**

- **Goal:** the two modules both `locators` and `compare` import, so those can then run in
  parallel.
- **Files:** `src/plumb/verify/__init__.py` (docstring stub + empty `__all__`),
  `src/plumb/verify/causes.py`, `src/plumb/verify/numbers.py`, `tests/verify/__init__.py`,
  `tests/verify/test_causes.py`, `tests/verify/test_numbers.py`.
- **causes.py:** string constants for every PRD M5 cause (C3's re-exported from
  `plumb.run.causes` where they exist; `ENTRYPOINT_MISSING`/`_AMBIGUOUS` from the exception
  classes' `cause`; `ENV_BUILD_FAILED` new), `CAUSES: frozenset[str]`, `RESERVED =
  frozenset({"PROPOSER_UNGROUNDED", "MODEL_ONLY_SIGNAL"})` (disjoint from `CAUSES`),
  `class BindingInvalid(ValueError)`.
- **numbers.py:**
  - `strict_decimal(text: str) -> Decimal | None` — `^\s*[+-]?(\d+(\.\d*)?|\.\d+)([eE][+-]?\d+)?\s*$`
    only; rejects `,`, `%`, `inf`, `nan`, `_`; rejects > 40 significant digits or adjusted
    exponent outside [−40, 40] (keeps all later arithmetic exact under the pinned context).
  - `half_unit(d: Decimal) -> Decimal` = `Decimal((0, (5,), d.as_tuple().exponent - 1))`.
  - `Tolerance(kind: "abs"|"rel", value: Decimal)` — frozen dataclass, lives here (not in
    `bindings.py`) so `compare` can start as soon as V0 lands.
  - `CONTEXT` — `decimal.Context(prec=100, rounding=ROUND_HALF_EVEN, traps=[InvalidOperation,
    Inexact, Overflow, DivisionByZero])`; callers use `CONTEXT.add/subtract/multiply/abs` or
    `with localcontext(CONTEXT)`.
- **Tests first:** vocabulary equals the PRD M5 list exactly; RESERVED disjoint; strict
  accept/reject table (`"0.87"`, `" -1.5e3 "`, `".5"` accept; `"1,000"`, `"87%"`, `"NaN"`,
  `"inf"`, `"0x1"`, `"1_0"`, `""` reject); `half_unit` spec criterion 7 values; a 41-digit
  string rejected.
- **Validation:** `uv run pytest tests/verify -q` green; full suite green.
- **Commit:** `Add C4 foundation: closed cause vocabulary and strict decimals`

### Phase L1: bindings file (RED → GREEN)

- **Goal:** spec criteria 1–2.
- **Files:** `src/plumb/verify/bindings.py`, `tests/verify/test_bindings.py`.
- **API:** frozen dataclasses (`Tolerance` imported from `numbers.py`),
  `JsonPointer(pointer: str)`, `StdoutRegex(pattern: str)`, `CsvCell(column: str,
  key_column: str, key_value: str)`, `Binding(claim_id, artifact, locator, tolerance, scale,
  invalid: str | None)`; `Bindings = Mapping[str, Binding]` (a `MappingProxyType`, sorted by id);
  `load_bindings(raw: bytes, claim_ids: Iterable[str]) -> Bindings`.
- **Rules:** decode UTF-8 and `json.loads(raw, parse_float=Decimal, parse_int=Decimal,
  parse_constant=_refuse)` so a numeric tolerance is detectable as non-`str`. Whole-file
  `BindingInvalid` per spec list (message names the `claim_id` or index). Per-entry locator
  validity sets `invalid = "BINDING_INVALID"` with a detail: RFC 6901 syntax (`""` or starts with
  `/`; `~` followed only by `0`/`1`), `re.compile` error or `groups != 1`, `csv_cell.row` not
  exactly one key. `artifact == "<stderr>"` → `BindingInvalid`; a `stdout_regex` whose artifact
  isn't `<stdout>`, or a `json_pointer` not on `.json` / `csv_cell` not on `.csv` →
  `BINDING_INVALID`.
- **Validation / commit:** `uv run pytest tests/verify/test_bindings.py`;
  `Load bindings: strict schema, named BindingInvalid, no float tolerances`.

### Phase L2: locate (RED → GREEN)

- **Goal:** spec criteria 3–8.
- **Files:** `src/plumb/verify/locate.py`, `tests/verify/test_locate.py`,
  `tests/verify/helpers.py` (shared: `make_checkout`, `run_program(tmp_path, program,
  checkout=None) -> (RunResult, Capture)` built on C3's `run_entrypoint` + `capture_outputs`
  with a stub `EnvBuild`, mirroring `tests/run/test_capture.py:38-58`).
- **API:** `Located(text: str, value: Decimal, half_unit: Decimal, relpath: str, sha256: str)`;
  `Unlocated(cause: str, detail: str)`; `locate(binding, capture) -> Located | Unlocated`.
- **Order inside `locate`:** `binding.invalid` → `Unlocated(BINDING_INVALID)`; target in
  `{s.relpath for s in capture.stale}` → `STALE_ARTIFACT` (**before** any read; helper
  `_stale_target(binding, capture) -> bool` kept as a separate function — `verdict-seam`'s
  mutation check patches it); target not in `capture.locatable` → `NO_BINDING`; else
  `data = capture.read(artifact)` (never catch its `ValueError`) → locator.
- **JSON:** `object_pairs_hook` raises an internal `_DuplicateKey` → `AMBIGUOUS_BINDING`
  (conservative: any duplicate anywhere in the document, since `json` can't scope it to the
  path — note this in the docstring). Pointer walk: dict key (unescape `~1`→`/`, `~0`→`~`), list
  index (`0` or no leading zero, in range); miss → `NO_BINDING`. Leaf: `Decimal` (not `bool`) →
  located text = the literal as written (re-scan: keep the `Decimal` built by `parse_float`,
  whose `str()` preserves the literal's digits/exponent); `str` → `strict_decimal`; else
  `UNPARSEABLE_VALUE`. NaN/Infinity → `parse_constant` raises → `UNPARSEABLE_VALUE`.
- **stdout:** decode UTF-8 strict (error → `UNPARSEABLE_VALUE`); `list(re.finditer)` count rule;
  group text → `strict_decimal`.
- **CSV:** decode `utf-8-sig`; `csv.reader`; empty file → `NO_BINDING`; header counts rule; key
  rows by exact string equality after `strip()`; ragged row shorter than the column index →
  `NO_BINDING`.
- **Tests:** one per cause; happy path per locator from a real run
  (`print(json.dumps({"metrics": {"auc": 0.8712}}))` style programs writing files); spy
  `Capture.read` via `monkeypatch.setattr(Capture, "read", ...)` for the stale test; tampered
  store raises `ValueError`; `type(located.value) is Decimal` and `str(located.value) ==
  "0.8712"`.
- **Validation / commit:** `uv run pytest tests/verify`;
  `Locate bound values by hash: JSON pointer, stdout regex, CSV cell`.

## File-by-file build order

1. `src/plumb/verify/causes.py` — vocabulary, `BindingInvalid`; deps `plumb.run.causes`.
2. `src/plumb/verify/numbers.py` — `strict_decimal`, `half_unit`, `CONTEXT`; stdlib.
3. `src/plumb/verify/bindings.py` — `load_bindings`, binding types; deps 1, 2.
4. `tests/verify/helpers.py` — synthetic run helpers; deps `plumb.intake`, `plumb.run`.
5. `src/plumb/verify/locate.py` — `locate`; deps 1–3, `plumb.run.capture`.

## Testing strategy

Unit tests per phase above, written first. Integration: L2's happy paths run real local
programs through C3 (subprocess legal, sockets blocked). Command: `uv run pytest tests/verify`.

## Environment & determinism

No env vars, no network, no clock. JSON/CSV parsing is order-preserving and deterministic;
`Bindings` iterates in sorted `claim_id` order.

## Edge cases & error handling

Covered in phases: duplicate JSON keys, BOM, ragged CSV, JSON `true` (a `bool` is an `int`
subclass in Python — check `bool` first), `-0`, pointer `/a~1b`, regex matching empty string.
`Capture.read`'s integrity `ValueError` propagates — a tampered store is never a verdict.
